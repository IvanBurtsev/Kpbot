# Состояние проекта kpbot

**Дата:** 25 ноября 2026
**Версия в работе:** ветка `main`, последний коммит — см. `git log -1`
**Тестов:** 257, все зелёные

---

## 1. Коротко

Сервис превращает письмо с заявкой в коммерческое предложение: разбирает позиции,
сопоставляет с прайсом, считает НДС, готовит PDF/DOCX/Excel, отправляет клиенту и
уведомляет менеджера в Telegram и MAX.

**Продукт функционально закрыт для одного пилота.** Не готов к продаже без:
переезда сервера в РФ, документов по персональным данным и одного живого клиента.

### HTTP-сервис 1С (готово 26.11.2026)

OData в Бухгалтерии на Fresh не принимает табличную часть документа, поэтому добавлен
второй путь: HTTP-сервис, который пишет счёт средствами самой 1С.

- `deploy/1c/kpbot-invoice.bsl` — готовый обработчик: JSON → «Счёт на оплату покупателю»
  с позициями, НДС, складом и проведением;
- `docs/ONE_C_HTTP_SERVICE.md` — контракт, установка, права, проверка через `curl`;
- `KPBOT_ONE_C_SERVICE_URL` и `1c-invoice --via service|auto|odata` в kpbot;
- `1c-price --apply` — цены из регистра «Цены номенклатуры» (на тестовой базе пусто);
- повторная выгрузка счёта не создаёт дубль: номер хранится в журнале решений,
  `--force` — для осознанного повтора;
- тесты клиента (успех, отказ 1С, HTTP-ошибка, отсутствие адреса) — 31 тест в `test_one_c.py`.

Осталось проверить на живой базе, где сервис опубликован: до публикации OData-путь
работает только на чтение.

## 6. Техническое состояние

| Параметр | Значение |
|---|---|
| Сервер | один VPS, Ubuntu, systemd, порт 8100 закрыт наружу |
| Доступ | HTTPS через DuckDNS, сертификат до 10.02.2027 |
| Cron | опрос почты каждые 10 мин, бэкап в 3:00 (все клиенты), очередь отправки каждые 30 мин |
| Сторож | проверка каждые 5 мин, сообщение в Telegram и MAX |
| Мультитенантность | отдельная база на клиента, реестр, панель владельца `/ui/ops` |
| Тесты | 257, изолированный прогон: свой каталог данных, боевой `.env` не читается, сеть запрещена (`KPBOT_OFFLINE=1`) |
| Проверка окружения | `python scripts/doctor.py`: секреты, каналы, база, мусор в папке |
| PDF | Chrome на сервере (2,4 с, 55 КБ), WeasyPrint как резерв |
| Ресурсы | 981 МБ свободной памяти, 19 ГБ диска |
