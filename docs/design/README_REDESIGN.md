## 🎨 ДЛЯ ДИЗАЙНЕРА

## 🆘 ЧТО ДЕЛАТЬ ЕСЛИ ЧТО-ТО НЕ ТАК

### Проблема: Таблица смотрится узко
**Решение:** `th, td { padding: 12px; }` — это не узко, это плотно (B2B). Оставить как есть.

### Проблема: На мобильном всё мелко
**Решение:** Это нормально! 480px + font-size: 16px + min-height: 44px на кнопках. Если нужна больше, добавьте `@media (max-width: 360px)` со скейлированием.

### Проблема: Старый дизайн выглядел лучше
**Решение:** Вероятно, привычка. Новый дизайн следует современным стандартам (Stripe, Linear, Material Design 3). Дайте пользователям неделю для адаптации.

### Проблема: Нужна тёмная тема
**Решение:** В app.css уже есть заготовка `@media (prefers-color-scheme: dark)`. Раскомментируйте и определите цвета.
