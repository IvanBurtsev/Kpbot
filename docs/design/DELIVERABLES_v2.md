## 🔧 ЧТО БЫЛО ИСПРАВЛЕНО (5 ПУНКТОВ)

### 1. CSS для мобильных неполный
**Было:** На 480px сжимаются только отступы `padding: 8px`, колонки остаются в строке.  
**Решение:** `@media (max-width: 768px) { display: block; }` + `display: grid` для `<td>`.

### 2. Нет data-label в HTML
**Было:** Невозможно показать подписи колонок в card-view.  
**Решение:** Добавлены `data-label` в каждый `<td>` всех таблиц (~65 атрибутов).

### 3. Класс .cards не определён
**Было:** `inbox.html:48` и `prices.html:33` используют `class="cards"` (опечатка).  
**Решение:** Переименованы на `class="cards-table"`, добавлены стили в CSS.

### 4. Формы внутри таблиц давят друг друга
**Было:** На мобильном `.line-form { gap: 8px }` → элементы в одной строке, кнопки < 44px.  
**Решение:** `.form-actions` обёрнуты, `flex-direction: column` на мобильном, `min-height: 44px`.

### 5. Нет разделения между desktop/mobile layout
**Было:** `@media (max-width: 480px)` меняет только font-size, `display: table` остаётся.  
**Решение:** 3 точки разлома (768px, 480px, 1025px) с полной трансформацией layout.

## 🔍 ТЕХДЕТАЛИ

### Как работает трансформация?

**Шаг 1: Скрыли заголовки таблицы**
```css
@media (max-width: 768px) {
  .cards-table thead { display: none; }
}
```

**Шаг 2: Строки → блоки (каждая на 100% ширины)**
```css
.cards-table tr {
  display: block;
  border: 1px solid var(--line);
  margin-bottom: 12px;
}
```

**Шаг 3: Ячейки → сетка (2 колонки: подпись + значение)**
```css
.cards-table td {
  display: grid;
  grid-template-columns: 100px 1fr;  /* Левая (подпись) и правая (значение) */
  gap: 8px;
}
```

**Шаг 4: Подписи из attr(data-label)**
```css
.cards-table td::before {
  content: attr(data-label);  /* Берёт текст из HTML атрибута */
  font-weight: 600;
  color: var(--muted);
  /* ... */
}
```

**Результат:** Каждая ячейка `<td>` выглядит как:
```
Подпись (жирно, серо)
Значение (тёмно)
```

### Почему не JavaScript?

**Требование:** "Jinja2 + один static/app.css, без фреймворков и внешних CDN".

**Решение:** Pure CSS3 `display: grid` + `attr()` функция (работает в Chrome 90+, Safari 15+, Firefox 88+).
