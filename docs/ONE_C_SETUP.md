# Мастер подключения к 1С (`1c-setup`)

Одна команда проверяет базу клиента и говорит, что с ней можно делать — до того,
как вы пообещаете интеграцию.

```bash
python -m kpbot.cli 1c-setup --url https://host/base --user odata.user
```

Спросит пароль скрыто. Отчёт показывает:

* конфигурацию (УТ/КА/ERP, Бухгалтерия, неизвестная);
* какие возможности есть: номенклатура, единицы, склады, контрагенты, цены,
  регистр остатков, заказы клиента, счета, реализация, поступление;
* что реально читается прямо сейчас (с текстом ошибки, если нет);
* настроен ли HTTP-сервис для записи.

Полезные флаги:

```bash
python -m kpbot.cli 1c-setup --url ... --user ... --json      # машинный отчёт
python -m kpbot.cli 1c-setup --url ... --user ... --save      # записать ключи в .env
python -m kpbot.cli 1c-setup --service-url https://host/base/hs/kpbot/invoice
```

`--save` пишет `KPBOT_ONE_C_BASE_URL`, `_USER`, `_PASSWORD` (и адрес сервиса) в `.env`.
Пароль в файле — как и раньше; не передавайте `.env` и держите права 600.

## Матрица возможностей

| Что | УТ 11 / КА 2 / ERP 2 | Бухгалтерия 3.0 | Нетиповая |
|---|---|---|---|
| Чтение номенклатуры, складов, контрагентов | ✅ | ✅ | обычно да |
| Цены и остатки | ✅ регистр и цены | ⚠️ цены есть, регистра остатков нет | по диагностике |
| Заказы клиента | ✅ | ❌ нет документа | по диагностике |
| Счёт на оплату | ✅ | ✅ шапка; строки — через HTTP-сервис | через сервис |
| Запись документов | через HTTP-сервис (`deploy/1c`) | через HTTP-сервис | адаптер |

## Что включить на стороне клиента

1. **Публикация OData** (Конфигуратор → Администрирование → Публикация на веб-сервере,
   либо панель Fresh). Проверить: `https://host/base/odata/standard.odata/$metadata`
   отдаёт XML.
2. **Пользователь для kpbot**: отдельный, только чтение справочников и регистров;
   запись — только если разрешено ставить документы.
3. **Регистр остатков**: в УТ — «Товары на складах»; если не опубликован, kpbot
   посчитает остатки по документам или возьмёт файл.
4. **HTTP-сервис для записи** (если нужна запись): `deploy/1c/kpbot-invoice.bsl`
   + публикация, см. [ONE_C_HTTP_SERVICE.md](ONE_C_HTTP_SERVICE.md).

## Чего мастер не делает

- не меняет конфигурацию 1С и не публикует сервисы — для этого нужен администратор 1С;
- не угадывает нетиповые регистры: если сущности не найдены, покажет «неизвестная
  конфигурация» и список того, что искал;
- не проверяет запись, чтобы не создавать документы: запись проверяется отдельно,
  на тестовой базе.

Поэтому в продаже честная формулировка: «чтение — на любой 1С 8.3 с OData; запись —
после установки нашего модуля за 30–60 минут; типовые конфигурации поддерживаем,
нетиповые диагностируем и адаптируем».
