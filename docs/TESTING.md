# Тесты

## Полный прогон

Тесты используют общий каталог `.tmp`: модули подхватывают настройки первого
импортированного модуля. Поэтому при повторных прогонах в одном рабочем каталоге
там накапливаются заявки и выученные пары — часть проверок может упасть не из-за кода.

Правило: перед полным прогоном удалить `.tmp`:

```bash
rm -rf .tmp        # Windows: Remove-Item -Recurse -Force .tmp
python -m unittest discover -s tests
```

В CI рабочая копия всегда чистая, поэтому там проблема не проявляется.
