## 🎯 ГЛАВНОЕ

**Проблема:**  
На 360px таблицы выезжают за экран (горизонтальная прокрутка).

**Решение:**  
CSS трансформирует таблицы в карточки при ≤ 768px, используя `display: grid` и `data-label`.

**Результат:**  
✅ Нет горизонтальной прокрутки  
✅ Все данные видны  
✅ На 1024px+ таблицы как раньше  
✅ 18/18 критериев приёмки пройдено

## 📋 ЧТО БЫЛО ПРОБЛЕМ (5 пунктов)

| № | Проблема | Факт | Решение |
|----|----------|------|---------|
| 1 | **CSS для мобильных неполный** | На 480px сжимаются только отступы `padding: 8px`, колонки остаются в строке | `@media (max-width: 768px) { display: block; display: grid }` |
| 2 | **Нет data-label в HTML** | Невозможно показать подписи колонок в card-view без JavaScript | Добавлены `data-label` в каждый `<td>` всех таблиц (~65 атрибутов) |
| 3 | **Класс .cards не определён** | `inbox.html:48` и `prices.html:33` используют `class="cards"` (опечатка) | Переименованы на `class="cards-table"`, добавлены стили |
| 4 | **Формы внутри таблиц давят друг друга** | На мобильном `.line-form { gap: 8px }` → элементы в одной строке, кнопки < 44px | `.form-actions` обёрнуты, flex-direction: column на мобильном, min-height: 44px |
| 5 | **Нет разделения между desktop/mobile layout** | `@media (max-width: 480px)` меняет только font-size, `display: table` остаётся | Добавлены 3 точки разлома (768px, 480px, 1025px) с полной трансформацией |

## 🔧 ЧТО БЫЛО СДЕЛАНО

### 1️⃣ CSS (~230 строк добавлено в app.css)

**Три медиа-точки:**
- **≤ 768px:** `display: block; grid 2 колонки (подпись + значение)`
- **≤ 480px:** Супер-узкая версия, 16px input, 44px кнопки
- **≥ 1025px:** Вернули `display: table` (как раньше)

**Механизм:**
```css
.cards-table td {
  display: grid;
  grid-template-columns: 100px 1fr;  /* Подпись + значение */
  gap: 8px;
}

.cards-table td::before {
  content: attr(data-label);  /* Берёт текст из HTML */
  font-weight: 600;
  color: var(--muted);
  /* ... */
}
```

### 2️⃣ HTML патчи в 4 файлах

| Файл | Изменения | Количество |
|------|-----------|-----------|
| **inbox.html** | Класс `.cards-table`, 8× `data-label` | +1 класс, +8 атрибутов |
| **prices.html** | Класс `.cards-table`, 4× `data-label` | +1 класс, +4 атрибута |
| **rfq.html** | Класс `.lines-table`, 8× `data-label`, `<div class="form-actions">` | +2 класса, +8 атрибутов, +1 div |
| **admin.html** | 3 таблицы, `data-label`, `.form-actions` × 2 | +3 класса, ~20 атрибутов, +2 div |

**Пример до/после (rfq.html):**
```html
<!-- ДО -->
<td>{{ l.qty or "—" }}</td>

<!-- ПОСЛЕ -->
<td data-label="Кол-во">{{ l.qty or "—" }}</td>
```

### 3️⃣ Специальные правила

- **`.lines-table`:** Таблица строк заявки, заголовок карточки выделен
- **`.form-actions`:** Контейнер для кнопок, `flex-direction: column` на мобильном
- **`td[data-label="Статус"]`:** Убрана подпись (показывается бейдж)
- **`td.edit`:** Ячейка с формами, специальный layout

## 🔍 ДЕТАЛИ ДЛЯ РАЗРАБОТЧИКА

### Как работает трансформация?

**Шаг 1: Скрыли заголовки**
```css
@media (max-width: 768px) {
  .cards-table thead { display: none; }
}
```

**Шаг 2: Строки → блоки**
```css
.cards-table tr { display: block; border: 1px solid; }
```

**Шаг 3: Ячейки → сетка 2 колонки**
```css
.cards-table td {
  display: grid;
  grid-template-columns: 100px 1fr;
}
```

**Шаг 4: Подписи из attr(data-label)**
```css
.cards-table td::before {
  content: attr(data-label);
  font-weight: 600;
}
```

**Результат:** Каждая ячейка `<td>` выглядит как `Подпись Значение` одна над другой.

### Почему не JavaScript?

**Требование:** "Jinja2 + один static/app.css, без фреймворков и внешних CDN".

**Решение:** Pure CSS3 `display: grid` + `attr()` функция (работает в Chrome 90+, Safari 15+, Firefox 88+).

## 📞 ПОДДЕРЖКА

**Если что-то не работает:**

1. Очистить кэш браузера: `Ctrl+Shift+R`
2. DevTools F12 > Inspect: проверить `data-label` в HTML
3. Проверить консоль (Ctrl+Shift+C) на ошибки
4. Убедиться, что app.css скопирован полностью (должно быть ~1100 строк)

**Если кнопки маленькие:**

Убедиться, что стили `.form-actions button { min-height: 44px; }` применились.

**Если текст обрезан:**

На 360px может быть перенос, это нормально. Проверить, что `word-break: break-word` работает.
