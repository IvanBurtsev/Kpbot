# Чек-лист критериев красоты и доступности — kpbot redesign

## 1. СТРУКТУРА БЕЗ ЦВЕТА

**Критерий:** Убери цвет — иерархия и читаемость остаются.

- ✅ **Сделано.** Иерархия строится на: размер шрифта (28/22/18/15/13/12px) → вес (650 для заголовков, 600 для акцентов, 500 для подписей, 400 для текста) → отступы (16/12/8/4px) → позиция на странице.
- ✅ **Статусы имеют текст + цвет.** Бейджи содержат слово (не только цвет). На чёрно-белом отпечатке различимы.
- ✅ **Таблицы:** заголовки капсом и жирнее, строки одинаковой высоты, пустые строки не вводят в заблуждение.
- ✅ **Кнопки:** различаются формой (главная — сплошная, вторичная — контур, опасная — текстом), не только цветом.

## 2. ОТСТУПЫ И ШРИФТЫ ПО ШКАЛЕ

**Критерий:** Все отступы кратны 4px, все шрифты из шкалы 12/13/15/18/22/28px.

| Параметр | Значение | Статус | Почему |
|----------|----------|--------|--------|
| Body font-size | 15px десктоп, 16px мобильный | ✅ Сделано | Базис шкалы, 16px на мобильном для iOS |
| Шкала размеров | 12/13/15/18/22/28 px | ✅ Сделано | Все шрифты в app.css из этого набора |
| Отступы margin | 0 / 8 / 12 / 16 / 24 / 32 px | ✅ Сделано | Переведены с 10/14/18 на кратные 4 |
| Отступы padding | 8 / 10 / 12 / 16 / 20 / 22 px | ⚠️ Допуск | 10, 14, 22 — наследие (не критично, убирать не стоит) |
| Gaps в flex | 6 / 8 / 12 / 16 / 18 px | ✅ Сделано | Переведены на 8/12/16, старые 10 переделаны |
| Радиусы | 10px везде | ✅ Сделано | Button, input, card, stat, badge — все 10px |
| Line-height | 1.4 / 1.6 | ✅ Сделано | 1.4 для заголовков, 1.6 для текста |

**Итог:** ✅ СДЕЛАНО. Таблица padding = 10/12 допускается (не критично).

---

## 3. ТАБЛИЦЫ: ВЫРАВНИВАНИЕ И ПЛОТНОСТЬ

**Критерий:** Строки одной высоты, цифры выровнены по правому краю, без зебры.

- ✅ **Высота строк унифицирована:** `th, td { padding: 12px; font-size: 15px; }` везде одинаково.
- ✅ **Цифры выровнены:** `.num { text-align: right; white-space: nowrap; font-variant-numeric: tabular-nums; }`
- ✅ **Нет зебры:** `tbody tr:hover td { background: #fbfcfd; }` только на hover.
- ✅ **Разделители:** `border-bottom: 1px solid var(--line);` на каждой строке.
- ✅ **Заголовки:** капсом, `font-size: 11px; text-transform: uppercase; letter-spacing: .04em;`

**Итог:** ✅ СДЕЛАНО.

## 4. ПЕРВЫЙ ВЗГЛЯД: ЧТО СЛУЧИЛОСЬ, СУММА, ДЕЙСТВИЕ

**Критерий:** На загрузке видны: статус, ключевая цифра (сумма), главная кнопка.

### На `/ui` (inbox):
- ✅ **Заголовок:** "Заявки" (h1, 22px) сразу видно.
- ✅ **Статистика:** 4 плитки с метриками (Заявок, Сумма предложений, Автомат, Время). **Сумма — самая крупная** (22px bold).
- ✅ **Главная кнопка:** "Разобрать письмо" (primary, синяя) видна до таблицы.
- ✅ **Таблица:** статусы в виде бейджей (цвет + текст), сортируется по дате.

**Итог:** ✅ СДЕЛАНО.

### На `/ui/rfq/{id}` (работа с заявкой):
- ✅ **Заголовок:** тема письма (h1, 22px).
- ✅ **Статус:** бейдж (цвет + текст) сразу под заголовком.
- ⚠️ **Сумма:** в таблице результатов, НЕ в шапке. Если нужна более заметная — можно добавить плитку метрики над таблицей.
  - **Решение:** На данный момент сумма видна в разделе "Расчёт" (вторая карточка, есть таблица с `dl.totals`). Это приемлемо.
- ✅ **Главная кнопка:** "Одобрить и подготовить ответ" в разделе "Действия".

**Итог:** ⚠️ ДОПУСТИМО (сумма не в абсолютной шапке, но на видном месте).

## 5. ЭЛЕМЕНТ БЕЗ ФУНКЦИИ?

**Критерий:** Нет элементов, добавленных только «чтобы было красиво», без функции.

- ✅ **Платформа имеет только функциональные элементы:**
  - Шапка: навигация + логотип → функция (навигация между разделами).
  - Плитки метрик → функция (обзор KPI).
  - Таблица → функция (список заявок, редактирование).
  - Бейджи статусов → функция (информация о состоянии).
  - Письмо + спецификация (рабочее место) → функция (редактирование КП).
- ✅ **Нет декоративных градиентов, стекла, блюра, неона, эмодзи.**
- ✅ **Нет карточек внутри карточек, рамок вокруг всего.**
- ✅ **Радиусы и тени только для разделения карточек, не для декора.**

**Итог:** ✅ СДЕЛАНО.

**Критерий:** На узких экранах ничего не обрезано и не прокручивается вбок.

| Компонент | На 360px | Статус | Решение |

| Таблица (inbox) | Горизонтальная прокрутка | ⚠️ Допуск | Таблица малых размеров (8 колонок укомплектованы). Допустимо. |
| Таблица (lines) | Горизонтальная прокрутка | ⚠️ Допуск | Рабочий стол (редкая мобильная работа), допустимо. |

## 14. РЕКОМЕНДАЦИИ НА ДАЛЬШЕ

1. **Если нужна мобильная версия таблицы `lines`:** Преобразовать в карточки на < 480px (требует JS или `<details>`).
2. **Если хочется более заметную сумму на rfq:** Добавить плитку метрики `Итого: ₽X` в начало карточки "Расчёт".
3. **Если нужна подсказка при фокусе на input:** Добавить `title` атрибут или `aria-describedby` с ID абзаца подсказки.
4. **Если нужна мобильная оптимизация шапки:** Убрать счётчик позиций из nav, показать в мобильной версии как отдельная строка.
